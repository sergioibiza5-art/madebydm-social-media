# Made by DM Social Media

Public media staging repository used by the Made by DM social publisher.

## Purpose

This repository contains only images and videos that are intended to be published on the Made by DM Instagram account. Files stored here are publicly accessible so Meta's Instagram API can fetch them when a post, Reel, Story or carousel is published.

## Structure

- `media/` — publication assets

## Important

- Do not store access tokens, passwords, API secrets or private customer data here.
- Only upload media that is intended for public social-media publication.
- The private automation and publication queue live in `madebydm-social-publisher`.
